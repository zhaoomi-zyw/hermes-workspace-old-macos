## 三、逐笔复盘：为什么规则会拦下它们

### ❌ 9/1 买星网 @40.59 → −212（−5.22%）

**规则判定**：**差②③**
```
星网锐捷 9/1  现价 39.75  MA60 27.05  ②值 0.23  量比 1.17
```
**②值 0.23** = 距 20 日最高点仅 **0.23 个 ATR** → **几乎贴在最高点** → **教科书级追高**
**★ 这笔是在 8/31 涨停的次日买入** —— **正是你实盘最大亏损模式的重复**

### ❌ 9/3 买紫光 @37.67 → −227（−6.03%）

**规则判定**：**差②③**
```
紫光股份 9/3  现价 38.13  MA60 34.71  ②值 1.57  量比 0.85
```
**②值 1.57** < 2.5 → **回调不充分**（当时用的是已作废的"方案A 回撤5%"口径 → 对高波动股等于半山腰）
**★ 这笔正是促成"方案A作废 + BUY-LOW-v1 冻结"的直接原因**

### ❌ 9/8 买云南铜业 @18.31 ×200 → −220（−6.01%）

**规则判定**：**②值 = −0.20（负数！）**
```
云南铜业 9/8  现价 18.32  MA60 16.36  ②值 −0.20  量比 1.71
```
**②值为负** = **价格已在 20 日最高点之上** → **不是回调，是突破**；**量比 1.71 = 放量**
**★ 这是「右侧放量突破追入」** —— 你 2026-09-08 已明确停用该类信号，但这笔发生在停用当天前后

**⭐⭐ 最讽刺的一点**：**当天（9/8）三条件真正全满足的是「赤峰黄金」** ——
```
赤峰黄金 9/8  现价 44.20  MA60 37.58  ②值 3.04  量比 0.78  ✅全满足
```
**如果当时已有今天这套低吸监控，它推给你的会是赤峰（当天 44.20），而不是你实际买入的云南（18.31×200）。**

### ❌ 9/10 买星网 @35.96 → −216（−6.01%）

## 五、⭐ 三条最重要的教训

**① 亏损模式高度一致：都在"离 20 日高点很近"或"放量"时买入**
```
9/1 星网  ②值 0.23  ← 贴最高点
9/3 紫光  ②值 1.57  ← 回调不足
9/8 云南  ②值 −0.20 ← 已在最高点之上 + 放量 1.71
9/10 星网 ②值 2.29  ← 差 0.21
9/11 赤峰 量比 1.18 ← 放量
```
**条件②（防追高）与③（防情绪高点）如果早就上线，这 5 笔一笔都不会发生。**

**② 9/8 那天规则放行的是赤峰，实盘买的是云南**
这最能说明监控的价值：**同一时刻，规则能区分"该买的"和"想买的"。**

**③ 9/15 之后的 2 笔买入（沈飞、赤峰）都走了监控流程**
**规则切换后，操作方式确实变了** —— 从"自己找"变成"等推送"。

## 六、⚠️ 必须同时讲清的局限

| 局限 | 说明 |
|---|---|
| **③ 用日线全天量比近似** | 线上是「同刻量比」。9/14 星网差 0.001、9/16 沈飞日线不符但线上推送 → **口径差异会影响个别判定** |
| **样本仅 21 天** | **极短**。不能据此断言"新策略整体更优" |
| **事后视角** | 回放本身无未来函数（H20 已 shift），但**解读时已知结果**，存在归因偏差风险 |
| **基准问题** | 只对比"买没买"，**未计算"若不买这 5 笔、资金闲置的收益"** |
| **单一市场环境** | 2026-09 上中旬为特定行情，不可外推 |

**⚠️ 因此本复盘的结论应表述为**：
> **"在本期内，BUY-LOW-v1 的拦截与实盘亏损高度吻合"** ——
> **不能说"新策略已被证明更优"**（样本太短），**但可以说"它拦下的正是亏的那些"**。

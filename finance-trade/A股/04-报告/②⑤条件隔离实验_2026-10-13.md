## 四、结论

### 1. **② 是整套规则的命门**

```
关掉 ② →  交易 121 → 216 笔（+78%）
          费用 1,408 → 2,458 元（+75%）
          收益 +11.73% → −3.36%（由正转负，−15.1pp）
          盈亏比 1.134 → 0.982（跌破 1）
```
**② 不只是「过滤条件」，它是这套系统正收益的全部来源。** 没有它，BUY-LOW-v1 是亏的。

### 2. **⑤ 是净正向的 —— 它在「净化」，不是「削减信号」**

```
加上 ⑤ →  交易 121 → 104 笔（−17 笔，−14%）
          收益 +11.73% → +13.67%（+1.94pp）
          盈亏比 1.134 → 1.168（改善）
          费用 1,408 → 1,220（省 188 元）
          Calmar 0.529 → 0.567（改善）
          唯一代价：回撤 −22.17% → −24.11%（多 1.94pp）
```
**⑤ 砍掉的那 14% 交易，整体是负贡献。**

### 3. **⑤ 救不回 ② 的缺失**

```
C（无②，无⑤）−3.36%  →  D（无②，+⑤）+0.26%
```
即使加上 ⑤，没有 ② 依然远差于基线 ⇒ **② 不可替代**。

### 4. **⭐ 回测与实况的接合（解释「零推送」）**

```
3 年全窗口：⑤ 只挡 14% 的交易        ← 温和筛选
当前弱市：  ⑤ 挡掉 100% 末段候选（0/18）← 完全静默
```
**两者不矛盾**：⑤ 只作用于「已过 ①②③ 的深回调候选」，而弱市里这类形态罕见、
且几乎必然跑输指数 ⇒ **静默本身就是它在工作（regime-dependent，不是失灵）**。

**补充证据**：⑤ 于 9/28 拦下星网锐捷（RS20 −4.3%），该股 9/28 收 32.99 → 10/13 收 27.67，
**跌 16.1%**（同期沪深300 仅 −1.2%）⇒ 至少有一次是精准避险。
（⚠️ 只陈述事实，不评分。）

## 五、必须随结论一起看的边界

1. **引擎口径 ≠ 线上 v1.2** —— 引擎是 `BUY-LOW-v1`（③=0.80、**无 ⑥、无弱市门**）。
   本实验测的是「**在三条件之上加 ⑤**」，**不等于完整 v1.2**。
2. **样本内**：3 年 / 单一池 12 只 / 每臂 104~216 笔。
3. **+1.94pp 在 104~121 笔样本上可能不显著** —— 本报告**不做显著性声明**。
4. **费率未校准**（`summary.json.assumptions.fee_calibration = UNCALIBRATED`），
   但**所有臂共用同一模型**（隔离实验期间不得引入新费率）。
5. ⛔ **不得据此调参** —— 「样本内回测数字不作为剔除/调参依据」是既定铁律。
   本轮结论的正确用途是「**⑤ 值不值得保留**」，不是「该不该改阈值」。

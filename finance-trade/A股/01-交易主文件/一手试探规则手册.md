# 一手试探执行规则（Trial Lot Rulebook）

> 版本：1.0  |  创建：2026-08-31  |  适用：空仓/低仓位时的建仓试探
> 定位：Omi 的 A股一手（100股）试探建仓的明确执行规则，与 DSA 系统结合

## 一、核心理念

一手（100股）是**试探仓**，不是重仓。目的是：
- 用最小成本验证判断、观察走势
- 错了损失小（约 -3~4%），对了再顺势加仓
- 避免"看对方向却因犹豫错过，或一上来重仓被套"

**铁律：一手只能出现在 DSA 买入/低吸信号出现之后，绝不追高。**

---

## 二、触发条件（何时买一手）

**严格按 signal_daily.py 的 DSA 逻辑，只有出现以下信号才买一手：**

1. **缩量回踩支撑企稳（SIG-001，首选）**
   - 条件：价格回踩20日支撑位(前20日最低, .shift(1)) + 缩量(量<均量×0.8) + 站上MA60 + 当日收阳
   - 信号标签：【低吸】现价接近支撑位(≤支撑×1.03)

2. **放量突破压力（SIG-002，次选）**
   - 条件：收盘>20日压力位(前20日最高, .shift(1)) + 放量(量>均量×1.5) + 站上MA60
   - 信号标签：【买入】放量突破压力位

**禁止追高：**
- 现价已涨（今日涨幅>3%）但无DSA买入信号 → 不买
- 信号是【关注】(接近压力)但未突破 → 不买，等突破确认
- 信号是【卖出】或【观望】→ 不买

---

## 三、买入动作（买一手时）

| 项 | 规则 |
|----|------|
| **股数** | 100股（1手） |
| **价位** | 信号触发价附近（低吸位/突破位），挂单买 |
| **买入依据** | 明确记录：触发的是哪个信号（SIG-001/002）、支撑/压力位、现价 |
| **成本记录** | 立即记入 signal_daily.py HOLDINGS + 记忆 |

---

## 四、止损规则（一手买入后）

**止损位 = 跌破买入时的关键支撑位，或固定 -4%：**

| 情况 | 止损 |
|------|------|
| 低吸买入（SIG-001） | 跌破20日支撑位下方（约 -4%），或跌破 MA20 |
| 突破买入（SIG-002） | 跌破突破位（压力转支撑），约 -3~4% |
| 统一底线 | **单笔一手最大亏损约 200-400元**（视股价），设好止损不等反弹 |

**止损纪律：**
- 跌破止损位 → 立即执行，不扛单（一手损失小，不值得扛）
- 不因"等反弹""等发布会"等理由延迟止损

---

## 五、加仓规则（一手确认后）

**一手试探成功后，何时加仓（200/300股）：**

| 确认信号 | 加仓动作 |
|----------|---------|
| 站上 MA5 且放量 | 加至 200股（再买100股） |
| 站上 MA10 且趋势确认向上 | 可加至 300股（但总仓位≤70%） |
| 跌破 MA5（刚加仓后） | 减回 100股，重新等确认 |

**加仓前提：**
- 一手已有浮盈（方向验证正确）
- 原支撑/止损位未破
- 现金充足，加仓后单票仓位≤70%（你现金12,827元，单票一手3,900元占30%，加到3手约39%）

---

## 六、止盈规则

| 情况 | 动作 |
|------|------|
| 涨到20日压力位 | 卖100股锁利（分批） |
| 从「近20日最高点」回撤8% | 止盈离场（移动止盈，让利润奔跑） |
| 涨过目标位且放量 | 可留一部分博更高，但至少锁一半利润 |

---

## 七、完整流程示例

```
1. DSA扫描（晨报/每小时/收盘前）发现 紫光股份 出现【低吸】信号
   → 回踩支撑36.9 + 缩量 + 站上MA60
2. 用100股试探买入 @37.0（记录：SIG-001低吸，支撑36.9）
3. 设止损 35.5（支撑下方约-4%）
4. 观察：
   - 若站上MA5(37.5)且放量 → 加至200股
   - 若跌破35.5 → 止损离场（亏损约-150元）
5. 涨到压力位 → 分批止盈锁利
```

## 八、纪律检查清单（每次买入前自问）

- [ ] 是否出现 DSA 买入/低吸信号？（不是我想买，是系统触发）
- [ ] 是否站上 MA60？（下跌趋势不接飞刀）
- [ ] 是否缩量回踩 或 放量突破？（不是追高）
- [ ] 止损设好了吗？（跌破关键位就走）
- [ ] 现金够吗？加仓后单票≤70%？
- [ ] 不是报复性买入（刚止损后别立刻买回同一只）

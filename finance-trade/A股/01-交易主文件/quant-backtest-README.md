## 使用流程
```bash

source .venv/bin/activate

# 2. 拉取数据（近5年前复权日线）
python fetch_data.py

# 3. 跑 MA5/10 回测，输出对比报告
```

## A股交易规则（已内建）
- T+1：当日买入次日可卖
- 涨跌停：涨停不可买，跌停不可卖（主板±10%）
- 费用：佣金万2.5 + 印花税千1(卖) + 过户费万0.1 + 滑点0.1%
- 整手：100股起，按手买入

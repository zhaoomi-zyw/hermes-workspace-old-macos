# finance-trade

Omi 的金融相关内容归档（A股 + 基金分开管理）。

## 目录结构

```
finance-trade/
├── A股/                          ← 股票交易、回测、DSA分析
│   ├── 01-交易主文件/            ← 权威持仓/纪律/交易历史（Obsidian主文件）
│   ├── 02-回测与策略/            ← 回测脚本 + 策略模块(sell_policy/dsa_strategy)
│   ├── 03-数据/                  ← 自选股日K数据（14只，前复权）
│   ├── 04-报告/                  ← 回测HTML报告 + 蒙特卡洛 + 策略迁移记录
│   └── 05-交易记录/              ← trade_journal.json(逐笔) + signal_library.json
└── 基金/                          ← 基金定投相关
    └── 定投监控/                  ← 申购限额监控脚本 + 状态
```
